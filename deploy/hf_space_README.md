# AgentSentinel: public demo

This is the dashboard for [AgentSentinel](https://github.com/Adi-2494/agentsentinel), a security layer for AI coding tools.

- **Overview / Live Guard / Merge Gate:** clearly labelled **synthetic demo events**.
- **Benchmark and Real-world data:** the project's measured results, including real GitHub Security Advisories, real prompt-injection data and SecurityEval.

This demo makes no LLM calls and holds no credentials.
